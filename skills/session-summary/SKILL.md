# Session Summary

現在のセッションの会話内容を分析し、構造化された日本語の要約Markdownファイルを生成する。

## ワークフロー

### 1. 会話を分析する

現在のセッション全体を振り返り、以下を特定する:

- 議論されたトピック（時系列順）
- 各トピックの背景・内容・結果
- 明示的な決定事項とその理由
- 作成・変更されたファイル
- 技術的な発見や学び
- 未完了のタスクや次のステップ

### 2. 要約を生成する

[summary-template.md](references/summary-template.md) のフォーマットに従って要約を作成する。

重要なルール:
- 言語は常に日本語
- 議論の流れを時系列で正確に再現する
- 決定事項には「なぜ」を併記する
- コード変更がないセッションでは「作成・変更したファイル」セクションを省略する
- 簡潔に、しかし重要な文脈は省略しない

### 3. ファイルとして保存する

- ファイル名: `session-summary-YYYY-MM-DD-{短い説明}.md`
- 保存先: 現在の作業ディレクトリ
- 例: `session-summary-2026-02-18-generative-art.md`

保存後、ファイルパスをユーザーに伝える。
