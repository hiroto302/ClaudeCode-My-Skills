# Fortune

今日の日付とユーザーの星座・血液型を組み合わせて、詳細な運勢レポートを生成する占いスキル。同じ日に複数回実行しても同じ結果を返す（キャッシュ方式）。

## ストレージ

- **プロファイル**: `~/.claude/fortune/profile.json` — 星座と血液型を保存（初回のみ作成）
- **日次キャッシュ**: `~/.claude/fortune/cache/YYYY-MM-DD.json` — その日のレポート全文を保存

これらは `~/.claude/` 配下に置き、プロジェクトリポジトリから分離する。

## ワークフロー

### Step 1: プロファイル読み込み

`~/.claude/fortune/profile.json` を Read ツールで確認する。

**存在する場合**: 中の `sign`（星座）と `bloodType`（血液型）を取得して Step 2 へ進む。

**存在しない（または読み込み失敗の）場合**: AskUserQuestion で順に聞く。

1問目: 星座
- 12択（牡羊座, 牡牛座, 双子座, 蟹座, 獅子座, 乙女座, 天秤座, 蠍座, 射手座, 山羊座, 水瓶座, 魚座）
- AskUserQuestion は最大4択なので、3問に分けて段階的に絞り込むか、4択×複数質問でカバーする。実装簡略化のため、まず「春生まれ/夏生まれ/秋生まれ/冬生まれ」のように4グループに分け、次の質問でその中から選ばせる **2段階方式** を採用する。
  - グループ A（牡羊・牡牛・双子）
  - グループ B（蟹・獅子・乙女）
  - グループ C（天秤・蠍・射手）
  - グループ D（山羊・水瓶・魚）
- 1問目で4グループから1つ選ばせ、2問目で該当グループ内の3星座（+ 「他」を含めた4択）から選ばせる。

2問目: 血液型
- 4択（A型, B型, O型, AB型）

回答取得後:
1. `mkdir -p ~/.claude/fortune` を Bash で実行
2. `~/.claude/fortune/profile.json` に Write で保存:
   ```json
   {"sign": "魚座", "bloodType": "A"}
   ```

### Step 2: 当日キャッシュ確認

今日の日付を `YYYY-MM-DD` 形式で取得する（システムプロンプトの `currentDate` または `date +%Y-%m-%d` を使用）。

キャッシュパス: `~/.claude/fortune/cache/YYYY-MM-DD.json`

**存在する場合**: ファイルを Read で読み、JSON 内の `report` フィールド（レポートMarkdown全文）を **そのままチャットに出力**してワークフロー終了。新しい運勢を生成しない。

**存在しない場合**: Step 3 へ進む。

### Step 3: 運勢を生成

[references/report-template.md](references/report-template.md) のフォーマットに厳密に従い、以下の要素を含むレポートを生成する。

**生成ルール**:
- 日付・星座・血液型の組み合わせを文脈として活用し、自然な内容にする
- **総合運**: ★1〜★5の5段階評価 + 「大吉/中吉/小吉/吉/末吉」のいずれか + 2〜3文の総評
- **恋愛運・仕事運・金運・健康運**: それぞれ1〜3行の具体的アドバイス
- **ラッキー要素**: カラー（具体的な色名）、ナンバー（1〜99の整数）、アイテム（身近な物）、方角（東西南北・東南など）
- **今日のひとこと**: 1〜2文の前向きな励ましのメッセージ

**トーン**:
- 前向きで、決めつけず提案調（「〜してみると吉」「〜を意識すると良いでしょう」）
- 占い雑誌風の柔らかい文体
- 具体的すぎる予言（金額・時刻・人名など）は避ける

### Step 4: 表示とキャッシュ保存

1. 生成したレポートMarkdownを **チャットにそのまま表示** する
2. `mkdir -p ~/.claude/fortune/cache` を Bash で実行
3. `~/.claude/fortune/cache/YYYY-MM-DD.json` に Write で保存:
   ```json
   {
     "date": "YYYY-MM-DD",
     "sign": "魚座",
     "bloodType": "A",
     "report": "# 🔮 今日の運勢\n..."
   }
   ```

### Step 5: フッター案内

レポート表示後、最後に以下の1行を案内する（初回作成時・キャッシュからの再表示時の両方で）:

```
> プロファイルを変更したい場合は `~/.claude/fortune/profile.json` を編集してください。
```

## 注意事項

- 同じ日に2回目以降の実行では、必ずキャッシュを返すこと（再生成しない）。これは「占い」としての一貫性のため。
- プロファイルファイルに想定外の値が入っていた場合（手動編集ミスなど）は、Step 1 の AskUserQuestion からやり直す。
- 出力は常に日本語。
- 占いは娯楽である旨を強調する必要はないが、断定的な言い回しは避ける。
