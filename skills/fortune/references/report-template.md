# 運勢レポートテンプレート

このテンプレートに **厳密に** 従ってレポートを生成すること。プレースホルダ `{...}` を実際の値で置き換える。

## フォーマット

```markdown
# 🔮 今日の運勢

**日付**: {YYYY-MM-DD}（{曜日}）
**星座**: {星座}
**血液型**: {血液型}型

---

## 総合運: {★★★★☆} {大吉/中吉/小吉/吉/末吉}

{2〜3文の総評。今日のテーマや全体的な流れを語る}

## 💕 恋愛運

{1〜3行。具体的なアドバイスや傾向}

## 💼 仕事運

{1〜3行。具体的なアドバイスや傾向}

## 💰 金運

{1〜3行。具体的なアドバイスや傾向}

## 🌿 健康運

{1〜3行。具体的なアドバイスや傾向}

---

## 🍀 今日のラッキー

- **カラー**: {色名}
- **ナンバー**: {1〜99}
- **アイテム**: {身近な物}
- **方角**: {方角}

## 💫 今日のひとこと

> {1〜2文の前向きなメッセージ}
```

## 記入ガイド

### 総合運の星評価
- ★★★★★ = 大吉
- ★★★★☆ = 中吉
- ★★★☆☆ = 小吉
- ★★☆☆☆ = 吉
- ★☆☆☆☆ = 末吉

最低でも ★1（末吉）以上を割り当て、★0 のような評価は避ける（占いの娯楽性のため）。

### カラー例
桜色, 紅, 山吹, 翡翠, 群青, 藤色, 白磁, 漆黒, 茜色, 若草, 浅葱, 茜, 銀鼠, 金茶 など。
カタカナの一般的な色（ピンク, ブルー, グリーン）でも可。

### アイテム例
身近で前向きに連想できる物を選ぶ。
例: ハーブティー, 万年筆, 観葉植物, アロマキャンドル, 文庫本, スマートフォンの新しい壁紙, お気に入りのマグカップ, 散歩用の靴, ノート, 香水, ハンカチ。

### 方角
東, 西, 南, 北, 北東, 東南, 南西, 北西。

### トーン
- 提案調を基本とする（「〜してみると吉」「〜を意識すると良いでしょう」「〜が運気を高めます」）
- 否定形より肯定形（「〜は避けて」より「〜を選ぶと安心」）
- 占いとして読んで楽しい、温かい雰囲気を保つ
